## Pruebas y ejecución

Registro de esta cohorte; resultados definitivos se actualizan después de ejecutar comandos:

- `npm run check`: el primer pase encontró una advertencia de accesibilidad del modal; se sustituyó por `<dialog>` nativo. La revisión posterior terminó con **0 errores y 0 advertencias**.
- `cargo test --locked --quiet`: pase final con **135 aprobadas, 21 omitidas y 0 fallidas (156 total)**. El primer intento de los tests de rendimiento se bloqueó por un JAR todavía no construido y se probó con override temporal de recursos. El JAR real ya existe y el pase completo no requiere ese override.
- `cargo test --quiet tp_client::tests`: **7 aprobadas**, incluyendo fallo real por archivo bloqueado y preservación de cambios del usuario. El test PNG adicional rechaza corrupción que intentaba pasar por deduplicación.
- `cargo test --quiet ffmpeg_synthetic_mp4_is_verified_without_audio -- --ignored`: **1 aprobada** tras validar formato, ausencia de audio y dimensiones 320×180 sin ampliación. No captura datos personales.
- `node scripts/test-cape-ui.mjs`: el coordinador registró un pase aprobado del editor y sus decisiones de compatibilidad con IPC simulado; no es un login real ni una prueba de backend remoto.
- `npm run build:client`: **24 pruebas Java aprobadas**, incluidas cuatro de distribución, y JAR final con SHA-256 `7ebbf3a4c64f6d9e1ec3f3cd931037803bd684e6390145c218c30e6941d15ba6`. Cada modificación del mod exige regenerar el manifiesto y repetir build antes de distribuir. El último ajuste de avisos se comprobó con geometría automatizada, sin atribuirle todavía QA visual posterior.
- `npm test` en `tp-api`: **29 aprobadas**, incluidos HTTP, PNG y PostgreSQL/PGlite con roles/RLS; no es una prueba del servicio Auth/Storage remoto. El backend permanece deshabilitado por defecto.
- Avisos de las nuevas dependencias de backend: `tp-api/THIRD-PARTY-NOTICES.txt` y licencias completas; pngjs 7.0.0 MIT (runtime), @types/pngjs 6.0.5 MIT y PGlite 0.5.14 Apache-2.0 (desarrollo), PostgreSQL con licencia propia. No se añaden al instalador Windows por esta tarea.
- Auditoría de comentarios: **329 archivos**, cero comentarios ordinarios, dos avisos legales y seis archivos wrapper con licencias preservadas. Auditoría de secretos: **998 textos, incluidos 542 blobs históricos**, cero coincidencias con los secretos locales comprobados y dos alertas de fixtures de Crash Doctor revisadas como falsos positivos. No equivale a cero alertas ni a una certificación absoluta de seguridad.
- Cobertura propia: restauración byte a byte con CRLF y claves desconocidas; bloqueo de edición manual; opciones antes inexistentes; rechazo UTF-8 inválido; verificación de backup; límites de rutas; RAM reservada; diagnóstico sin textos privados; filtrado de muestras y FPS sostenidos.
- No se modifican mundos ni cuentas reales para tests. Las pruebas de archivos usan carpetas temporales únicas y validan su ubicación antes de eliminarlas.
- Gradle, comportamiento dentro de Minecraft y rendimiento real se documentan en `TP_CLIENT_TEST_REPORT.md`. Un test unitario no acredita una sesión multijugador, un relay, una llamada de voz ni un benchmark A/B.
