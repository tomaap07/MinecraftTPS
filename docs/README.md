## Informes históricos

Los documentos fechados, revisiones de arquitectura, auditorías y notas de las compilaciones 0.1.1–0.1.3 describen el código y las pruebas en sus fechas. Algunas de aquellas compilaciones permitían perfiles locales sin una cuenta Microsoft previa; esa conducta se sustituye por la política actual. Se conservan esos registros para trazabilidad y no acreditan el comportamiento de la versión vigente ni una aprobación de Mojang.

La nueva versión de aplicación 0.1.0 es una renumeración explícita. Retirar las descargas antiguas de GitHub Releases no cambia la secuencia de commits, las etiquetas ni las limitaciones que se documentaron en el desarrollo. Las comprobaciones automatizadas y los análisis de seguridad describen su alcance; no constituyen certificaciones jurídicas, de seguridad o de compatibilidad universal.
